# CP422-Network-Intrusion-Detection

## Local Development Setup Guide

1. Run `git clone https://github.com/ShurjoMajumder/CP422-Network-Intrusion-Detection.git`
2. `cd` Into the project directory
3. Run `uv sync`
4. Run `git checkout -b <new branch name>`

You're now ready to make changes and push code. When done making changes, create a pull request on GitHub for the corresponding branch.

Data paths:

1. CSV files path: `/Volumes/workspace/default/cp422-unsw-nb15/raw/unsw/UNSW-NB15 dataset/CSV Files/`
